Format reference & example record 
{
  "format": "allmyprofiles-catalogue/1",
  "categories": [
    { "name": "Crypto", "icon_code": "currency-bitcoin",
      "bg_color": "#f7f3e8", "text_color": "#7a5b12", "sort_order": 10 }
  ],
  "sources": [
    { "name": "CoinMarketCap",
      "domains": "coinmarketcap.com",
      "url": "https://coinmarketcap.com/",
      "profile_pattern": "https://coinmarketcap.com/community/{handle}/",
      "bg_color": "#1e2026", "text_color": "#ffffff", "border_color": "#0b0c0f",
      "icon_code": "graph-up-arrow",
      "category": "Crypto",
      "cta": "Follow",
      "sort_order": 0,
      "is_active": true, "is_adult": false, "is_nofollow": false }
  ]
}

Required per source: name. Everything else falls back to safe defaults. domains = comma-separated bare hostnames (no http://). profile_pattern must contain {'{handle}'}. Colors must be hex (#rrggbb). Icons are Bootstrap Icons slugs without the bi- prefix. A source may reference a category created earlier in the same file. Category links are always resolved by label, never by database id. Custom icon uploads aren't part of the portable format (binary); re-attach them in the edit form after import.
